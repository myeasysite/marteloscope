# Marteloscope tree data

Веб-інструмент для польової прив'язки дерев марелоскопу за **азимутом і відстанню** від центрів ділянки, з картою, локальною системою координат X/Y та експортом у Sylvotech.

**Демо:** https://myeasysite.github.io/marteloscope/

## Можливості

- **Точки прив'язки** — центри ділянок і точки панорамної зйомки; координати вводяться вручну, беруться з GPS пристрою, **вибираються кліком по карті** або обчислюються від іншого центру за азимутом і відстанню.
- **Вибір точки на карті** — режим прицілу з банером-підказкою, тимчасовим маркером, який можна перетягнути, живим показником координат курсора та скасуванням клавішею Esc.
- **Перетягування об'єктів** — центри, панорами й окремі дерева пересуваються мишею. При зсуві центру всі його дерева перераховуються за збереженими азимутами й відстанями; при зсуві дерева розв'язується обернена геодезична задача і азимут з відстанню перераховуються назад.
- **Ввід дерев** — CSV у форматі `Номер, Азимут, Відстань, Порода, Діаметр (см), Висота (м)`, вставкою тексту або імпортом файлу.
- **Карта** — схема OpenStreetMap або супутник Esri, розмір маркера пропорційний діаметру, колір за породою, динамічна легенда.
- **Локальні координати X/Y** — перетворення WGS84 у плоску систему в метрах відносно обраного центру, з довільним кутом повороту та інтерактивним попереднім переглядом.
- **Експорт** — повна таблиця CSV, координати X/Y (усі об'єкти, окремо центри, окремо панорами) та формат Sylvotech з довідником ID порід і автозаповненням.
- **Автозбереження** у localStorage браузера.

## Використання

Проєкт не потребує збірки чи сервера — це один самодостатній HTML-файл. Достатньо відкрити `index.html` у браузері або скористатися посиланням на демо.

## Формат даних дерев

```
1, 45, 12.5, Сосна, 32, 24
2, 120, 8.3, Дуб, 44, 21
3, 270, 15.0, Береза, 28, 19
```

Роздільник — кома, крапка з комою або табуляція. Азимут у градусах від півночі за годинниковою стрілкою, відстань у метрах.

## Технології

Leaflet 1.9.4, Tailwind CSS, Lucide Icons. Обчислення координат — пряма та обернена геодезичні задачі на сфері (R = 6 371 000 м).
