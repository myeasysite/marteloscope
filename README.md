# Marteloscope tree data

Веб-інструмент для польової прив'язки дерев марелоскопу за **азимутом і відстанню** від центрів ділянки: карта, редагована таблиця, локальна система координат X/Y, тематична розмальовка, робота офлайн і експорт у Sylvotech.

**Демо:** https://myeasysite.github.io/marteloscope/

## Можливості

### Прив'язка точок
- Центри ділянок і точки панорамної зйомки.
- Координати вводяться вручну, беруться з GPS пристрою, **вибираються кліком по карті** або обчислюються від іншого центру за азимутом і відстанню.
- Режим вибору на карті: банер-підказка, тимчасовий маркер із перетягуванням, живий показник координат курсора, скасування клавішею Esc.
- Центри, панорами й окремі дерева пересуваються мишею. При зсуві центру дерева перераховуються за збереженими азимутами; при зсуві дерева розв'язується обернена геодезична задача.

### Дерева
- Ввід CSV у форматі `Номер, Азимут, Відстань, Порода, Діаметр (см), Висота (м)` — вставкою або імпортом файлу.
- **Редагована таблиця**: номер, порода, діаметр, висота, азимут і відстань змінюються прямо в рядку; зміна азимута чи відстані миттєво пересуває дерево на карті.
- Очищення всього списку дерев зі збереженням мережі точок.

### Візуалізація
- Схема OpenStreetMap або супутник Esri.
- Розмір маркера пропорційний діаметру.
- **Тематична розмальовка**: за породою, за ступенем товщини, за висотою або за центром — з динамічною легендою і підрахунком дерев у класах.

### Координати та експорт
- Перетворення WGS84 у локальну плоску систему X/Y у метрах відносно обраного центру з довільним кутом повороту та інтерактивним переглядом.
- Експорт: повна таблиця CSV, координати X/Y (усі об'єкти, окремо центри, окремо панорами), формат Sylvotech із довідником ID порід і автозаповненням.

### Робота офлайн
- Повноцінний PWA: застосунок встановлюється на телефон і працює без мережі.
- Бібліотеки Leaflet, Tailwind і Lucide лежать локально в `vendor/`, тож CDN не потрібен.
- Кнопка **«Зберегти видиму область»** завантажує плитки карти для поточного екрана на 1–4 рівні масштабу вперед — перед виїздом у ліс.

### Інше
- Інтерфейс українською та англійською з перемикачем у шапці.
- Збереження проєкту в локальний JSON-файл і завантаження назад.
- Автозбереження в браузері.

## Використання

Відкрийте демо-посилання або запустіть локально:

```bash
git clone https://github.com/myeasysite/marteloscope.git
cd marteloscope
python3 -m http.server 8000
```

Далі http://localhost:8000. Простого відкриття `index.html` подвійним кліком достатньо для базової роботи (бібліотеки підвантажаться з CDN), але service worker і офлайн-кеш вимагають http/https.

## Формат даних дерев

```
1, 45, 12.5, Сосна, 32, 24
2, 120, 8.3, Дуб, 44, 21
3, 270, 15.0, Береза, 28, 19
```

Роздільник — кома, крапка з комою або табуляція. Азимут у градусах від півночі за годинниковою стрілкою, відстань у метрах.

## Структура

```
index.html            застосунок (розмітка, стилі, логіка)
sw.js                 service worker: кеш оболонки та плиток карти
manifest.webmanifest  маніфест PWA
icons/icon.svg        іконка застосунку
vendor/               локальні копії Leaflet, Tailwind, Lucide
```

## Технології

Leaflet 1.9.4, Tailwind CSS, Lucide Icons, Cache API. Обчислення координат — пряма та обернена геодезичні задачі на сфері (R = 6 371 000 м).
